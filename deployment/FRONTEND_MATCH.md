# 프론트엔드 원본 일치 확인

**결과: 로컬 소스로 만든 운영용 빌드가 현재 서버의 배포 파일 6개와 모두 바이트 단위로 일치합니다.**

- 원본: `D:/Orca/hanjari-ai/frontend`의 현재 작업 파일
- 추가 위치: `hanjari-web/frontend/`
- 검사일: 2026년 10월 19일
- 환경: Windows, Node.js 24.15.0, npm 11.12.1
- 방식: 잠금 파일로 패키지 설치 → `build:prod` 실행(TypeScript 검사, `VITE_MOCK=0`) → SHA-256 비교

현재 서버 파일의 해시를 SSH로 읽어 기존 정리본과 같은지도 다시 확인했습니다. 서버 파일 수정·서비스 재시작은 하지 않았습니다. 로컬 원본도 수정하지 않고 별도 작업 폴더에서 빌드했습니다.

파일 이름뿐 아니라 전체 내용과 파일 목록이 일치합니다. 원본 57개를 추가했으며, 이 중 README와 `.gitignore`만 새 저장소의 안내·배포본 보관에 맞게 정리했습니다. 빌드에 사용하는 소스와 설정은 그대로입니다.

실제 `.env`, 설치 패키지, 테스트 결과·보고서는 포함하지 않았습니다. 기존 서버 배포 파일은 덮어쓰지 않았습니다.

이 확인으로 현재 로컬 소스에서 동일한 배포 화면을 재현할 수 있음을 확인했습니다. 특정 Git 커밋이나 작업자의 과거 기여 이력까지 확정한 것은 아닙니다. 테스트·문서처럼 운영 빌드에 들어가지 않는 파일은 배포 파일만으로 과거 버전을 확인할 수 없습니다.

세부 파일 해시와 패키지 버전은 `frontend-match.json`에 기록했습니다.
