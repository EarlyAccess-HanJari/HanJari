# 검증 기록

확인일: 2026년 10월 19일.

## 파일과 업로드 설정

- 서버에서 내보낸 파일 82개를 SHA-256으로 비교했습니다. 통계 CSV 포함을 위한 `hanjari-ml/.gitignore` 수정 외에 원본 차이는 없습니다.
- 내보내기 도중 선택한 서버 파일의 내용이 바뀌지 않았는지 확인했습니다.
- Python 파일 23개의 문법과 JSON 파일 형식을 확인했습니다.
- 포함 파일이 Git 제외 규칙에 잘못 걸리지 않는지 확인했습니다.
- 실제 `.env`, 개인 키, 로그, 학습 중간자료 등 제외 대상 경로 11개를 시험했습니다.
- 개인 키, GitHub 토큰, AWS 키, Discord 웹훅, URL·환경 변수에 직접 적힌 인증값 패턴을 검사했으며 발견된 항목은 없습니다. 서버 환경 파일의 실제 키 값과 비교하는 검사도 내보내기 중 수행했습니다.
- 모든 개별 파일이 100 MiB 미만입니다. 가장 큰 파일은 노선별 통계 CSV입니다.

## 샘플 API 확인

Windows / Python 3.12.14에서 운영 서버와 같은 주요 라이브러리 버전으로 검사했습니다. 운영 서버 자체는 Ubuntu / Python 3.11.16입니다.

총 12개 응답 확인을 통과했습니다.

- 상태 API와 기본 화면: 200
- 대기 인원 0·3·40명: 각각 200, 정류장 6곳의 결과, 확률 0~1
- 범위 밖 입력 -1·41명: 400
- 문자인 입력·누락된 입력: 422
- 화면의 아이콘·JavaScript·CSS: 200

외부 버스 API 호출은 차단한 상태에서 검사했으며 호출 시도는 없었습니다. 사용 자료는 포함된 2026년 9월 30일 샘플입니다.

**검사 조건:** Codex 검증 환경에서 XGBoost의 Windows 파일 경로 접근이 차단되어, 검사 도구에서 같은 모델 파일을 바이트로 읽어 메모리에 전달했습니다. 예측 모델이나 배포 소스는 수정하지 않았습니다. 따라서 이 결과는 샘플 모델과 API 연결 검사이며, 새 PC에서 원래 파일 읽기 방식으로 실행한 전체 설치 검증은 아닙니다.

브라우저 조작·화면 외관, 실시간 수집, 자동 재학습과 서비스 설치는 이번 로컬 검사에 포함하지 않았습니다. 수집기·일일 작업·감시 작업을 실행하거나 운영 서버를 재시작하지 않았습니다.

세부 응답과 실제 검사 버전은 `runtime-validation.json`에 기록했습니다.
