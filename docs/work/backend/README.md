## 현재 구성

- 웹: FastAPI와 빌드된 React 화면을 함께 제공합니다. 운영 릴리스는 `practical-20261105-v8`입니다.
- HTTPS: nginx가 443 포트를 받고, 일반 HTTP 요청은 HTTPS로 308 이동합니다. 2026-11-05 03:34(KST) 공개 8000 차단을 완료했습니다. uvicorn은 `127.0.0.1:8000`에만 바인딩하고 nginx만 내부에서 연결합니다. 2026-11-05 서버에서 내부 바인딩과 방화벽의 8000 허용 규칙 제거를 확인했고, 외부에서 HTTPS 200·HTTP 308·공개 8000 무응답을 확인했습니다.
- 응답: 저장된 수집 자료를 사용합니다. 조회마다 외부 버스 API를 호출하지 않습니다.

자세한 구성과 되돌리는 방법은 [운영 안내](../../../deployment/README.md)에 있습니다.

[공통 협업 안내](../../../CONTRIBUTING.md)의 Python 3.11 실행 방법을 따릅니다. 기본 샘플 모드는 API 키 없이 동작하며 9/30 저장 자료를 사용합니다. 주요 수정 위치는 `hanjari-web/backend/`입니다.

