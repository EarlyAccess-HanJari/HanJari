# 데이터 출처

## A. 서울시 버스노선별 정류장별 시간대별 승하차 인원 (CSV, 핵심)
- https://data.seoul.go.kr/dataList/OA-12913/S/1/datasetView.do
- 교통카드 기준, 월 단위, 서울시내·광역·**마을버스 포함**. 매월 5일 전월분 갱신.
- 2023-01 ~ 2026-08 월별 CSV 확인됨 (각 약 15MB). 2022년 이전은 연 단위 파일.
- 2022-07 이후 '교통수단타입명/코드' 컬럼 추가.
- 한계: 차량(회차) 단위 아님. 시간대 합계라 운행횟수로 나눠야 회당 값이 됨. 현금 승차 미집계(무시 가능).
- 다운로드: 사이트에서 직접 (JS 버튼). → `data/raw/seoul_hourly/`

## B. 서울시 노선별 정류장별 총 버스 운행횟수 (CSV)
- https://data.seoul.go.kr/dataList/OA-21220/S/1/datasetView.do
- A를 운행횟수로 나눠 "회당 평균 승하차/재차인원" 계산용. → `data/raw/seoul_trips/`
- 마을버스 포함 여부 미확인.

## C. 서울시 버스노선별 정류장별 (일별) 승하차 인원 (CSV, 선택)
- https://data.seoul.go.kr/dataList/OA-12912/S/1/datasetView.do
- 일별 합계(시간대 없음). 날짜 간 변동 확인용. → `data/raw/seoul_daily/`

## D. 실시간 버스도착정보 API (핵심, 자동 수집용)
- 서울시 버스도착정보조회 (공공데이터포털 https://www.data.go.kr/dataset/15000314/openapi.do / api.bus.go.kr)
- 첫째·둘째 버스의 도착예정시간, 차량번호, 혼잡도, 만차 여부 등 제공 (문서 기준).
- **성북02에 재차인원/혼잡도 값이 실제로 채워지는지 미확인.** 마을버스 혼잡도는 2023-12부터 일부 노선 시범 → 포함 여부 직접 확인 필요.
- 인증키: 서울 열린데이터광장 신규 발급이 막혔다는 공지가 있었음 → 공공데이터포털 키 또는 팀(유민준) 기존 키 사용.
- 필드명은 문서만 믿지 말고 실제 응답에서 확인할 것.

## E. (선택) 교통빅데이터 일자별-시간대별-노선별-구간별 승객수
- https://t-data.seoul.go.kr/category/dataviewopenapi.do?data_id=1025
- 구간별 재차인원을 일·시간 단위로 제공. 마을버스 포함 여부 미확인. A로 부족하면 검토.
