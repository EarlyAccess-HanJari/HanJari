# 데이터 출처

외부 사이트의 제공 기간·갱신 주기 등은 기존 조사 기록이며 2026-11-05 기준 미재확인입니다. 저장소의 처리 자료·샘플과 현재 코드에서 확인한 사용 현황을 함께 기록합니다. 계획 기준은 [PRD v1.8·WBS v1.11](../../docs/plan/)입니다.

## A. 서울시 버스노선별 정류장별 시간대별 승하차 인원 (CSV, 핵심)
- https://data.seoul.go.kr/dataList/OA-12913/S/1/datasetView.do
- 교통카드 기준, 월 단위, 서울시내·광역·**마을버스 포함**. 매월 5일 전월분 갱신.
- 2023-01 ~ 2026-08 월별 CSV 확인됨 (각 약 15MB). 2022년 이전은 연 단위 파일.
- 2022-07 이후 '교통수단타입명/코드' 컬럼 추가.
- 한계: 차량(회차) 단위 아님. 시간대 합계라 운행횟수로 나눠야 회당 값이 됨. 현금 승차 미집계 등 실제 인원과의 오차 가능성이 있으며 무시할 수 있는지 현장 검증 전입니다.
- 다운로드: 사이트에서 직접 (JS 버튼). → `data/raw/seoul_hourly/`

## B. 서울시 노선별 정류장별 총 버스 운행횟수 (CSV)
- https://data.seoul.go.kr/dataList/OA-21220/S/1/datasetView.do
- A를 운행횟수로 나눠 "회당 평균 승하차/재차인원" 계산용. → `data/raw/seoul_trips/`
- 저장소의 성북02·종로03 처리 CSV와 현재 피처에서 운행횟수를 사용합니다. 외부 데이터셋 전체의 마을버스 포함 범위는 2026-11-05 기준 미재확인입니다.

## C. 서울시 버스노선별 정류장별 (일별) 승하차 인원 (CSV, 선택)
- https://data.seoul.go.kr/dataList/OA-12912/S/1/datasetView.do
- 일별 합계(시간대 없음). 날짜 간 변동 확인용. → `data/raw/seoul_daily/`

## D. 실시간 버스도착정보 API (핵심, 자동 수집용)
- 서울시 버스도착정보조회 (공공데이터포털 https://www.data.go.kr/dataset/15000314/openapi.do / api.bus.go.kr)
- 첫째·둘째 버스의 도착예정시간, 차량번호, 혼잡도, 만차 여부 등 제공 (문서 기준).
- 저장소의 성북02·종로03 샘플과 현재 파서에서 재차 인원 필드를 사용합니다. 인원형 구분과 결측·자료 시각을 검사하며, API 인원은 실제 탑승 성공이나 현장 실측 인원과 동일한 정답이 아닙니다.
- 인증키는 환경변수·비공개 `.env`에서 관리합니다. 발급 가능 여부와 한도는 2026-11-05 기준 미재확인입니다. 실제 키는 문서·저장소에 기록하지 않습니다.
- 필드명은 문서만 믿지 말고 실제 응답에서 확인할 것.

## E. (선택) 교통빅데이터 일자별-시간대별-노선별-구간별 승객수
- https://t-data.seoul.go.kr/category/dataviewopenapi.do?data_id=1025
- 구간별 재차인원을 일·시간 단위로 제공. 마을버스 포함 여부 미확인. A로 부족하면 검토.

## F. 팀 직접 현장 관측 (예정)

11/9~11/13 전원이 각자 등교 때 앱을 쓰고 Google 스프레드시트에 기록해 API 기반 학습·평가와 분리합니다. 시간표와 영상 촬영은 쓰지 않습니다. 사용자 직접 제출 익명 탑승 기록은 수집 범위에서 제외합니다. 기록표는 공유했으며 현장 합격 기준은 11/6 준비 예정입니다. 자동 재학습은 계속하며 서비스 모델을 고정하지 않습니다. 최지용이 11/8 관측 전 모델과 11/9~11/13 관측 기간 모델 버전을 복사해 보관합니다. 최근 7개 버전만 남기는 정리에서 보관본이 삭제되지 않게 하고, 기록표 시각과 `models.csv`로 예측 모델을 찾습니다. 보관 작업은 아직 미실시입니다. 현장 평가가 완료된 것으로 해석하지 않습니다.
