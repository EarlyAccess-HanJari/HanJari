# 성북02 실용 정원 낮춤 (2026-11-17)

성북02 일반차(6418·6597·1601)를 38명에서 **35명**으로, 저상차(6419·6421)를 60명에서 **50명**으로 낮춥니다. 종로03(52·54명)은 그대로 둡니다. 모두 API 인원 기준 실용 정원이며 법정 정원이 아닙니다.

## 왜 다시 계산했나

11/4 계산(`src/exp_practical_capacity.py`)은 위치 API 구간으로 정류장 도착·출발 인원을 나눴습니다. 인원은 정류장을 떠난 뒤 약 27초 뒤에 반영되는데, 2번출구→녹십자는 약 30초라 녹십자 '도착 인원'에 2번출구 탑승분이 빠지고 녹십자 순승차에 섞였습니다. 이번에는 각 정류장 출발 뒤 35초 이후 첫 관측을 그 정류장 출발 인원으로 잡았습니다(`src/exp_capacity_aligned.py`). 성북02 아침 평균 순승차가 2번출구 +9.7명, 녹십자 +4.2명으로 나뉩니다(전에는 녹십자에 몰림).

## 운영 주의

모델 메타의 `capacity_policy`가 웹 정원표와 다르면 모든 예측이 '확률 보류(model_unverified)'가 됩니다. 정원을 바꿀 때는 새 정원으로 학습한 모델과 웹 설정을 같이 바꿉니다. 정원을 바꾼 뒤 예전 정원 모델로 되돌리면(`daily.py rollback`) 웹도 예전 정원 릴리스로 돌려야 합니다.
