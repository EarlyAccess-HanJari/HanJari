## API 인원을 믿을 수 있는가 (현장 계수 전 점검)

| 점검 | 결과 |
|---|---|
| 미태그 하차(공공 카드 18개월, 찍힌 승차 − 찍힌 하차) | 성북02 승객의 1.8%, 종로03 2.3% — 달마다 일정 |
| 종점 출발 직후 API 인원(거의 빈 차여야 함) | 중앙값 0명, 차량별 평균 0.3~2.8명, 아침 0.5 → 저녁 2~3명 |
| 차량 카운터 누적 | 없음. 혼잡 때 숫자가 큰 6421·5508 도 종점 직후는 0.3·2.3명 |
| 21명 제보 vs 53명 | 53명 5508 뒤 50초에 22명 3170 도착 — 차량 혼동 유력(화면 차량번호 표시는 v4 에서 수정) |

미태그로 생기는 오차는 평소 1~3명 수준이다. 큰 차이는 차량 혼동과 잘못된 정원(관측 최대)에서 나왔다. 이 문서의 수치는 모두 API 인원 기준이며, 현장 대조(차량번호·시각·인원)는 11주차 계획에서 확인해 정원을 고친다.
