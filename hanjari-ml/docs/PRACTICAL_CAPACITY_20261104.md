## 안내 규칙 변경(같은 날)

- '판단하기 일러요'를 내지 않는다. 범위가 넓어도 확률이 그 불확실성을 담는다.
- 정원을 넘은 만차 버스는 보류하지 않고 확률(거의 0)로 '어려울 수 있음'을 안내한다.
- 남는 보류: 정보 지연(180초)·인원 결측·일요일·공휴일·등록 안 된 차량·검증 데이터 부족 칸.
- 1~2정류장 전 확률은 과거 같은 칸(노선·정류장·거리·30분)의 실제 증가 분포로 낸 값보다 높게 말하지 않는다(몰림 과신 방지).
- 위치 API 가 빠지면 바로 앞 버스를 '주행 중'으로 보지 않고 정차 분포(넓은 쪽)로 계산한다(빠지면 0.92→0.99 로 과신했음).
- 과거 순증감 표(q_hist)는 날짜별 캐시를 합산해 만든다. 예전엔 export 가 원본을 다시 읽어 41일에 30분+, 서버는 압축 안 된 최근 3일만 읽어 학습과 서비스 표가 달랐다.
